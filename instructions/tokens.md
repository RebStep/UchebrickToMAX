# Где взять токены и ключи

! Все значения пишутся в файл `.env` в корне проекта.

## Данные, которые вы придумываете

`POSTGRES_PASSWORD`, `SESSION_SECRET`, `WEBHOOK_SECRET`, `ALICE_SECRET` - случайные строки, строки (50 символов) или можно сгенерировать:

```bash
openssl rand -hex 24
```

## GigaChat (обязательно)

1. Заходите на [developers.sber.ru/studio](https://developers.sber.ru/studio) через Сбер ID
2. Создаёте проект GigaChat API. Для физлиц - бесплатный тариф
3. В проекте: «Настройки API» → «Получить ключ». Копируете Authorization key
4. В `.env` пишете `GIGACHAT_CREDENTIALS=ключ`

## Распознавание голоса (обязательно)

В `.env` можно выбрать размер модели: `WHISPER_MODEL=small` (так по умолчанию, можно вообще не писать). Есть ещё `base` - быстрее, но хуже понимает, и `medium` - понимает лучше, но медленнее и просит больше памяти.

## Навык Алисы (ТОЛЬКО на сервере)
Публичный навык:

1. Придумываете `ALICE_SECRET`
2. Заходите на [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) → «Создать навык Алисы»
3. В Backend → Webhook URL пишете `https://ваш-домен/alice/ALICE_SECRET`, только вместо `ALICE_SECRET` сама ваша строка, а вместо `ваш-домен` - ваш домен
4. В MAX пишете боту `/link`, он пришлёт шесть цифр. Говорите Алисе в навыке «привяжи» и эти цифры
