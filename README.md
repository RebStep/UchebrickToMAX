# Учебрик

Бот для школьников в мессенджере MAX. Записывает домашку, дела и события из обычного сообщения, пересланного сообщения учителя или из чата (при добавлении его в школьную группу), голосовое не настроено из-за ограничений MAX (MAX не передаёт данные самого голосового боту). Напоминает вовремя, хранит файлы и ссылки к заданиям, следит за олимпиадами. Всё видно в удобном виде на карте и в календаре на сайте или в мини-приложении.
Предусмотрена синхронизация с календарями других сервисов, а также с голосовым помощником - Алиса

## Что умеет

- Задание можно написать, переслать или принять с чата, надиктовать в мини-приложении в окне создания нового дела. После чего задание разбирается и приходит пользователю на подтверждение, с функцией изменения определённых данных вручную 
- Несколько заданий в одном сообщении записываются по отдельности. Список можно загрузить командой `/import` текстом или файлом TXT/DOCX.
- Напоминания приходят одним сообщением на все дела, у которых подошло время. Повтор удаляет прошлое напоминание, так что в чате не копятся одинаковые сообщения
- В настройках можно изменять параметры под себя: по каким заданиям напоминать (все, выбранные, никакие), сколько раз повторять, тихие часы, утренний план, подбор времени для домашки
- Список дел по сегодняшнему дню, на неделю и все собираются в одном сообщении: Ключевая особенность закдючается в том, что отметить или изменить задание можно прямо в сообщении, нажав на эмодзи 🔲, ✏️, что сильно упрощает взаимодействие
- Фото и файлы, присланные боту, сразу ложатся на карту, а прикрепить их к заданию можно кнопкой под ответом или соответсвенно на сайте / в приложении. Всё хранится внутри карты (врменные ограничения по размеру файла 20 мб)
- В групповом чате класса бот замечает задания и присылает их черновиком в личку каждому участнику, кто запускал бота. Можно быстро отправить задание в свой список дел
- Календарь: подписка по ссылке в любом календаре, поддерживаемый ics записи
- Навык Алисы (настраивается отдельно): «что задано» и запись задания голосом
- В настрйоках можно поменять стили, подобранные по самому приложению MAX

## Из чего состоит

```
bot/            бот на Python
  bot_max/      обработчики сообщений и кнопок MAX
  core/         разбор заданий и дат, напоминания, работа с базой
  schema.sql    схема PostgreSQL, применяется при запуске бота
miniapp/        сайт и мини-приложение
  api/          сервер на Node.js (Fastify)
  web/          интерфейс на Vue 3
caddy/          настройки веб-сервера: локально и для домена
instructions/   инструкции по запуску
docker-compose.yml
.env.example    шаблон настроек
```

Запуск идёт одной командой:  `docker compose up --build -d`
